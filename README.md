# Конверкот

Local-first PWA для личных финансов: бюджет «план–факт», финансовые цели с расчётом взносов,
финансовый резерв и баланс семьи. Данные хранятся только на устройстве пользователя,
внешних запросов и аналитики нет.

## Команды

```bash
npm install
npm run dev        # разработка
npm run build      # сборка
npm run lint       # ESLint
npm run typecheck  # tsc
npm test           # модульные тесты
npm run coverage   # тесты с покрытием (порог для src/core — 95 %)
npm run e2e        # Playwright (сам собирает проект и поднимает preview)
```

Перед первым запуском e2e: `npx playwright install chromium`.

## Архитектура

```
src/core       чистые функции: деньги, даты, цели, бюджет, баланс (без React и хранилища)
src/db         Dexie: схема, миграции, репозитории (этап 2)
src/features   экраны вкладок; overview/widgets — виджеты дашборда и registry.ts
src/components общие компоненты и shadcn/ui
src/i18n       строки интерфейса на русском
```

## Внешние запросы

По умолчанию приложение не обращается в интернет вообще. Единственное исключение —
виджет «Новости»: он читает ленту, адрес которой вы указали сами, и только после того,
как вы включите внешние источники в настройках. Данные о финансах при этом не передаются.

## Дисклеймер

Расчёты носят информационный характер и не являются индивидуальной инвестиционной рекомендацией.
