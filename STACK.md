явно включённой настройке.

## Хранение данных

| Что                                              | Где                                     | Комментарий                                     |
| ------------------------------------------------ | --------------------------------------- | ----------------------------------------------- |
| Финансы (счета, операции, цели, планы, конверты) | IndexedDB, база `konvert-me`            | Схема v2, доступ только через репозитории       |
| Настройки приложения                             | Та же база, таблица `settings`          | Одна строка с ключом `app`                      |
| Раскладка «Обзора»                               | Та же база, таблица `dashboardLayouts`  | Порядок и размеры виджетов                      |
| Закладки и ленты новостей                        | Таблицы `links`, `feeds`, `feedItems`   | Ключи API — на устройстве, в ошибки не попадают |
| Тема оформления                                  | `localStorage`, ключ `konvert-me.theme` | Тёмная по умолчанию                             |
| Резервная копия                                  | JSON-файл у пользователя                | Необязательное шифрование AES-GCM + PBKDF2      |

## Внешние запросы

По умолчанию приложение **не делает ни одного запроса наружу**: ни
аналитики, ни сторонних скриптов, ни шрифтов с чужих доменов.

Единственное исключение — виджет «Новости»: он читает ленту по адресу,
который ввёл пользователь, и только после включения настройки «Разрешить
запрашивать ленты новостей». Запрос уходит без cookies и без referrer,
API-ключ (если задан) отправляется только на хост этой ленты.

## Команды

```bash
npm install          # установка зависимостей
npm run dev          # дев-сервер (http://localhost:5173)
npm run build        # проверка типов + production-сборка
npm run preview      # локальный просмотр собранного приложения

npm run lint         # ESLint, предупреждения запрещены
npm run typecheck    # tsc -b
npm test             # модульные тесты (Vitest)
npm run coverage     # тесты с покрытием: ядро — порог 95 %
npm run e2e          # Playwright: сам собирает проект и поднимает preview
npm run format       # Prettier

npm run icons        # перерисовать иконки из src/components/brand/cat-mark.ts
```

Перед первым запуском e2e: `npx playwright install chromium`.
