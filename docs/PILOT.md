# Пилот Конверкота

Выпуск MVP по плану (docs/PLAN.md, раздел «Релиз MVP»): публичный сайт с дисклеймером и политикой
конфиденциальности, затем пилот на 10–20 людях. Решение о следующих этапах принимается по итогам
пилота. Подготовлено в версии 0.17.0 (17.09.2026).

## 1. Что проверяем

Четыре числа из плана. Считаются по статистике, которую участники присылают сами (раздел 7).

| Метрика                 | Как считать                                                                                     | Ориентир |
| ----------------------- | ----------------------------------------------------------------------------------------------- | -------- |
| Прошли знакомство       | «Знакомство: пройдено» среди всех участников (пропуск не считается)                             | 70 %     |
| Создали цель            | «Целей, кроме резерва» не меньше 1                                                              | 50 %     |
| Вернулись через 7 дней  | «Открывали через 7 дней и позже: да» среди тех, у кого с первого запуска прошло 7 дней и больше | 40 %     |
| Вернулись через 30 дней | «Открывали через 30 дней и позже: да» среди тех, у кого прошло 30 дней и больше                 | 25 %     |

Ориентиры предварительные, поправьте под себя. Знакомые, которых позвали лично, обычно
возвращаются охотнее незнакомых, поэтому планка выше, чем у магазинных приложений.

Кроме чисел анкета отвечает на вопросы для этапов 9–10: на чём люди открывают Конверкот и
поставили бы они отдельную программу для Windows, Linux или Android.

Что делать с итогами:

- ориентиры достигнуты: браться за этапы 9–10 в том порядке, который подскажут ответы про устройства;
- знакомство или цели ниже ориентира: сначала поправить знакомство и первые экраны, потом новые платформы;
- возврат ниже ориентира: разобраться по анкетам, чего не хватило, прежде чем делать что-то новое.

## 2. Сайт

- Адрес: **https://konverkot.gitverse.site** (заработает после первой публикации, раздел 3).
- `/` лендинг, `/privacy` политика конфиденциальности, остальные адреса ведут в приложение.
  Кто уже открывал приложение на этом устройстве, с `/` сразу попадает в «Обзор».
- Установленное приложение открывается на `/overview`.
- **Адрес нельзя менять после начала пилота.** Данные участников лежат в браузере и привязаны к
  адресу сайта: на новом адресе приложение откроется пустым, перенести данные можно только файлом копии.
- Все настройки сайта в `src/app/site.json`: адрес, репозиторий публикации, ссылка на анкету,
  почта для вопросов, выключатель пилота.

### Почему GitVerse Pages

Бесплатно, российский сервис (СберТех), HTTPS, сайт в корне адреса и своя страница 404, поэтому
ссылка на любой раздел открывается с первого захода. Проверено 17.09.2026:

| Вариант            | Почему нет                                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------------------------- |
| SourceCraft Sites  | Отдаёт сайты с заголовком `worker-src 'none'`: service worker запрещён, без интернета приложение не работает  |
| GitHub Pages       | В мае и июле 2026 года в России были сбои доступа к GitHub; из приватного репозитория публикует только платно |
| Netlify, Vercel    | По сообщениям пользователей, Netlify в России не открывается, Vercel открывается не везде                     |
| Cloudflare Pages   | Cloudflare в России замедляют с 2025 года                                                                     |
| Beget (бесплатный) | По описанию тарифа, SSL-сертификата на бесплатном нет, а без HTTPS приложение не установить                   |

Когда мобильный интернет ограничен и работают только сайты из «белых списков», новый участник
может не открыть сайт. Выход: открыть его по Wi-Fi и установить приложение, дальше Конверкот
работает без сети.

## 3. Публикация: первый раз

Делается один раз, руками, в браузере и терминале.

1. Зарегистрируйтесь на [gitverse.ru](https://gitverse.ru).
2. Создайте организацию `konverkot`. Если имя занято или организацию создать нельзя, подойдёт
   ваш личный аккаунт: тогда в `src/app/site.json` замените `konverkot` в `origin` и
   `repository` на своё имя.
3. В организации создайте **публичный** репозиторий с тем же именем, что у владельца:
   `konverkot`. Только такой репозиторий публикуется в корне адреса. Пустой, без README.
4. Доступ для git. Проще всего по HTTPS с токеном: создайте токен доступа в настройках профиля
   GitVerse. При первой отправке git спросит логин и пароль: логин от GitVerse, вместо пароля токен.
   Чтобы не вводить его каждый раз в течение часа:
   ```bash
   git config --global credential.helper 'cache --timeout=3600'
   ```
   Если удобнее SSH-ключ, добавьте его в профиль и поставьте в `repository` SSH-адрес со страницы
   репозитория («Код» → «Клонирование» → SSH).
5. Опубликуйте сборку (раздел 4): `npm run deploy`.
6. В репозитории откройте «Настройки»: включите CI/CD, затем «Страницы» → источник «Ветка»,
   ветка `main`, папка корень, сохранить. Сборка страниц займёт несколько минут.
7. Проверьте:
   - https://konverkot.gitverse.site открывает лендинг;
   - https://konverkot.gitverse.site/privacy открывается сразу, без перехода с главной;
   - на телефоне приложение ставится на экран и открывается в режиме полёта;
   - превью ссылки в мессенджере показывает кота и название.

## 4. Обновление сайта

```bash
npm run deploy
```

Скрипт `scripts/deploy.mjs`:

1. Проверяет, что всё закоммичено: сайт собирается только из коммита, чтобы по версии всегда
   находился код.
2. Собирает приложение (`npm run build`).
3. Добавляет то, что нужно хостингу: `404.html` и копию страницы по каждому адресу приложения
   (список в `site.json`, тест `src/app/site.test.ts` сверяет его с вкладками), файл `.nojekyll`.
4. Кладёт сборку в клон репозитория сайта (папка `.deploy/`, в git проекта не попадает),
   коммитит «Конверкот <версия> (<коммит>)» и отправляет. Файлы прежних версий в `assets/`
   остаются: если хостинг или браузер ещё держит старую страницу, её скрипты не пропадут.

Проверить сборку, ничего не отправляя:

```bash
npm run deploy -- --dry-run
```

Участники получат новую версию сами: приложение покажет «Вышло обновление» и обновится по кнопке.

## 5. Анкета

Сервис: [Яндекс Формы](https://forms.yandex.ru), ответы хранятся в России. Форма без обязательных
личных полей, без входа по аккаунту. В описании формы: «Не пишите имена, телефоны и суммы».

Вопросы:

1. **Статистика из Конверкота** (длинный текст, необязательно). Подсказка: «Настройки» → «Пилот» → «Скопировать».
2. **Сколько вы пользуетесь Конверкотом?** Один вариант: открыл(а) пару раз / около недели / месяц и дольше.
3. **На чём вы его открываете?** Несколько: телефон на Android / iPhone / компьютер с Windows / компьютер с Linux / Mac / планшет.
4. **Было ли что-то непонятно в первых пяти вопросах?** Текст.
5. **Что оказалось полезнее всего?** Несколько: Обзор / Бюджет / Цели / Счета и долги / Вычеты / Финплан / Импорт выписок.
6. **Чего не хватило или что мешало?** Текст.
7. **Будете пользоваться дальше?** Один: да / скорее да / скорее нет / нет.
8. **Поставили бы Конверкот отдельной программой?** Несколько: на Windows / на Linux / на Android из RuStore или Google Play / хватает сайта.
9. **Насколько вероятно, что вы посоветуете Конверкот знакомому?** Шкала от 0 до 10.
10. **Нашли ошибку?** Текст: что делали и что пошло не так.

Когда форма готова: ссылку на неё в `feedbackFormUrl` в `src/app/site.json`, коммит, `npm run deploy`.
В карточке пилота и на лендинге появится кнопка «Открыть анкету», в политике конфиденциальности
ссылка на неё. Пока ссылки нет, приложение просит прислать статистику тому, кто пригласил.

## 6. Как проводить

**Кого звать.** 10–20 человек: разные телефоны и компьютеры, и те, кто уже ведёт бюджет, и те,
кто никогда не вёл. Лучше без финансовых специалистов: план писался для обычного человека.

**Приглашение** (поправьте под себя):

> Привет! Я делаю Конверкот: бесплатное приложение для личных финансов. Оно считает, сколько
> откладывать на цели, хватает ли бюджета и сколько налога можно вернуть. Регистрации нет, данные
> хранятся только у тебя на телефоне или компьютере.
>
> Попробуешь месяц? Открой https://konverkot.gitverse.site, ответь на пять вопросов и поставь
> приложение на экран. Через неделю и через месяц оно попросит поделиться впечатлениями, это пара минут.

**Что сказать участнику:**

- открыть ссылку по хорошему интернету и установить приложение (инструкция на лендинге);
- данные только на устройстве: раз в месяц сохранять копию («Настройки» → «Сохранить копию»);
- через неделю и через месяц появится плашка «Поделиться»: скопировать статистику и ответить на анкету.

**Календарь:**

| День  | Что делать                                                                                 |
| ----- | ------------------------------------------------------------------------------------------ |
| 0     | Разослать приглашение, помочь с установкой тем, у кого не получилось                       |
| 7–10  | Приложение напоминает само. Ответы приходят в анкету                                       |
| 30–33 | Второе напоминание приложения, вторая волна ответов                                        |
| 35–40 | Написать тем, кто не ответил: «Открой Конверкот, скопируй статистику из настроек и пришли» |
| 40–45 | Свести таблицу, посчитать метрики, прочитать ответы, решить про этапы 9–10                 |

## 7. Статистика участника

Лежит в «Настройках», карточка «Пилот: статистика и отзыв». Показывается целиком до копирования,
никуда не уходит сама. Что в ней: версия, сколько дней с первого запуска и в какие дни открывали
(номерами от первого дня), прошли ли знакомство, число целей, счетов, операций и операций из
выписок, месяцев с планом, лет во «Вычетах», расчётов в «Финплане», сохраняли ли копию, открывали
ли установленное приложение, телефон или компьютер. Сумм, названий, имён и дат нет.

Дни открытия приложение хранит в `localStorage` (`konvert-me.usage`), рядом с темой, отдельно от
базы: они не попадают в файл копии и стираются вместе со всеми данными. Лендинг и политика дни не
считают, только само приложение.

**Строка для таблицы.** Последняя строка статистики: значения через `;` в таком порядке:

```
версия;дней с первого запуска;дни открытия через пробел;через 7 дней;через 30 дней;знакомство;
целей;счетов и долгов;операций;из выписок;месяцев с планом;лет вычетов;расчётов финплана;
копия;установлено;экран
```

Вставьте строки в таблицу и разделите столбцы по `;` («Данные» → «Текст по столбцам»).

**Оговорка про день выгрузки.** Статистика считает и сегодняшний день. Если участник открыл
приложение только потому, что вы попросили прислать статистику (день 35–40 в календаре), этот день
не возврат: уберите последний номер из дней открытия и пересчитайте «через 7 дней» и «через 30 дней».
Напоминание самого приложения видно только тому, кто открыл его сам, поэтому ответы на него
считаются как есть.

## 8. После пилота

- В `src/app/site.json` поставить `"pilotActive": false`, закоммитить и опубликовать: пропадут
  раздел «Идёт пилот» на лендинге, напоминания и карточка пилота в настройках.
- Итоги и решение записать в docs/PLAN.md (раздел 8) и в CHANGELOG.
